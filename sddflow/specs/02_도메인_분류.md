# 도메인 분류

요구사항명세서(01_요구사항명세서.md)의 기능 11개를 사용자 관점에서 8개 도메인으로 묶는다.

---

## 도메인: 사용자/인증

### 행위 목록
- ID/비밀번호로 로그인한다
- 로그인 상태를 유지한다 (JWT 발급/검증)
- 로그아웃한다

### 포함 기능
- F001 로그인

### 의존하는 도메인
- 없음 (모든 다른 도메인의 진입 조건)

---

## 도메인: 일정

### 행위 목록
- 일정을 만든다 (제목, 시작/종료 시각, 장소)
- 일정을 조회한다 (캘린더 월/주 뷰)
- 일정을 수정한다
- 일정을 삭제한다
- 일정에 반복 규칙을 지정한다 (매일/매주/매월)
- 일정에 알림 시각을 지정한다 (시작 N분 전)

### 포함 기능
- F002 일정 생성·조회·수정·삭제
- F008 일정 반복

### 의존하는 도메인
- 사용자/인증: 로그인된 사용자의 일정만 다룸
- 연결: 일정 삭제 시 연결된 메모의 링크 해제
- 태그: 일정에 태그 부여
- 첨부: 일정에 파일 첨부
- 알림: 일정 시작 시각 기준으로 알림 생성

---

## 도메인: 메모

### 행위 목록
- 메모를 만든다 (제목, 본문 마크다운)
- 메모를 조회한다 (최근순 목록, 상세)
- 메모를 수정한다
- 메모를 삭제한다
- 메모 본문에 체크박스 항목을 관리한다 (마크다운 체크박스)

### 포함 기능
- F003 메모 생성·조회·수정·삭제
- F010 체크리스트

### 의존하는 도메인
- 사용자/인증: 로그인된 사용자의 메모만 다룸
- 연결: 메모 삭제 시 연결된 일정의 링크 해제
- 태그: 메모에 태그 부여
- 첨부: 메모에 파일 첨부

---

## 도메인: 연결 (일정-메모 링크)

### 행위 목록
- 일정에 새 메모를 붙인다 (신규 메모 생성 후 연결)
- 일정에 기존 메모를 붙인다
- 일정에 붙은 메모 목록을 본다
- 메모에서 일정을 만들고 양방향 연결한다
- 메모에 연결된 일정 목록을 본다
- 일정-메모 연결을 해제한다 (데이터는 양쪽 모두 유지)

### 포함 기능
- F004 일정에 메모 붙이기
- F005 메모에서 일정 만들기

### 의존하는 도메인
- 일정: 연결 대상
- 메모: 연결 대상
- 사용자/인증: 본인 자산끼리만 연결 가능

---

## 도메인: 태그

### 행위 목록
- 태그를 만든다 (이름, 상위 태그)
- 태그를 3단계 계층 구조로 관리한다
- 태그를 수정·삭제한다
- 일정·메모에 태그를 붙인다
- 태그로 일정·메모를 필터링한다

### 포함 기능
- F009 태그

### 의존하는 도메인
- 사용자/인증: 본인 태그만 관리

---

## 도메인: 첨부

### 행위 목록
- 일정/메모에 파일을 업로드한다 (이미지 jpg/jpeg/png/gif, PDF)
- 파일당 최대 10MB, 건당 최대 5개 제한을 지킨다
- 첨부 목록을 본다 (썸네일/파일명)
- 첨부를 미리보기/다운로드한다
- 일정/메모 삭제 시 첨부도 함께 삭제된다

### 포함 기능
- F011 첨부 파일

### 의존하는 도메인
- 일정: 첨부 대상
- 메모: 첨부 대상
- 사용자/인증: 본인 첨부만 접근

---

## 도메인: 검색

### 행위 목록
- 키워드로 일정(제목·장소)과 메모(제목·본문)를 함께 검색한다
- 결과 타입(전체/일정/메모)을 선택한다
- 태그로 추가 필터링한다
- 검색 결과에서 상세 화면으로 이동한다

### 포함 기능
- F006 통합 검색

### 의존하는 도메인
- 일정: 검색 원본
- 메모: 검색 원본
- 태그: 필터 조건
- 사용자/인증: 본인 데이터 내에서만 검색

---

## 도메인: 알림

### 행위 목록
- 일정 시작 N분 전 SSE로 알림을 받는다 (기본 30분 전)
- 알림 페이로드에서 연결된 메모 요약을 함께 본다
- 알림에서 일정 상세로 이동한다

### 포함 기능
- F007 일정 시작 알림

### 의존하는 도메인
- 일정: 알림 트리거 기준 (시작 시각, 알림 분)
- 연결: 알림에 붙은 메모 요약 포함
- 사용자/인증: 로그인된 세션의 SSE 연결만 유지

---

## 도메인 의존 관계 요약

```
사용자/인증 ← (진입 조건)
  ├── 일정 ────┐
  ├── 메모 ────┤
  │            ├── 연결 (일정↔메모 N:N)
  ├── 태그 → 일정/메모
  ├── 첨부 → 일정/메모
  ├── 검색 → 일정/메모/태그
  └── 알림 → 일정/연결
```

- 도메인 개수: 8개 (사용자/인증, 일정, 메모, 연결, 태그, 첨부, 검색, 알림)
- 기능 11개 모두 분류 완료
