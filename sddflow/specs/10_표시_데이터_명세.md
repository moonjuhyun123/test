# 표시 데이터 명세

기준 입력: 01_요구사항명세서.md, 03_ERD.md, 07_화면목록.md, 09_화면_상세_명세서.md

각 화면 컴포넌트가 실제로 보여주는/받는 데이터 항목을 ERD로 추적. 다른 모듈 테이블에서 오는 항목은 ★ 표시 (API 교차 조회 후보).

---

## S001: 로그인

### 표시 데이터 (시스템 → 화면)
| 영역 | 데이터 항목 | 타입 | 출처 | 비고 |
|------|-----------|------|------|------|
| 카드 | 앱 이름(로고 하단) | String | — | 정적 문자열 ("캘린더") |
| ErrorState | 실패 메시지 | String | — | 서버 error.message 전달 |

### 입력 데이터 (사용자 → 시스템)
| 행위 | 항목 | 타입 | 필수 | 검증 |
|------|------|------|------|------|
| 제출 | id | String | Y | 1~50자, 공백 불가 |
| 제출 | password | String | Y | 1자 이상 |

### 데이터 조합 요구
- `user` 단독 조회 (login_id 일치 + password_hash 매칭)
→ 최소 API 1개: `POST /api/auth/login`

## S003: 통합 검색 결과

### 표시 데이터
| 영역 | 항목 | 타입 | 출처 | 비고 |
|------|------|------|------|------|
| 툴바 | 현재 keyword | String | URL `q` | |
| 툴바 | 현재 type 필터 | enum(ALL/SCHEDULE/MEMO) | URL `type` | |
| 툴바 | 현재 tagIds | List&lt;Long&gt; | URL `tagIds` | |
| 툴바 TagPicker 옵션 | 태그 목록 | List&lt;TagSummary&gt; | `tag` 테이블 (본인) ★ | 필터 드롭다운 |
| 결과 항목(공통) | 타입 아이콘 | enum | 결과 타입(schedule/memo) | |
| 결과 항목(일정) | 제목 | String | `schedule.title` | |
| 결과 항목(일정) | 시간 범위 | DateTime×2 | `schedule.start_at`, `schedule.end_at` | |
| 결과 항목(일정) | 장소 | String | `schedule.location` | |
| 결과 항목(일정) | 태그 칩 | List&lt;TagSummary&gt; | `schedule_tag` JOIN `tag` ★ | |
| 결과 항목(메모) | 제목 | String | `memo.title` | |
| 결과 항목(메모) | bodyExcerpt | String | `memo.body` (앞 N자) | 계산값 |
| 결과 항목(메모) | updatedAt | DateTime | `memo.updated_at` | |
| 결과 항목(메모) | 태그 칩 | List&lt;TagSummary&gt; | `memo_tag` JOIN `tag` ★ | |
| Pagination | totalElements/totalPages/hasNext | Integer/Boolean | COUNT(*) | 계산값 |
| EmptyState | 안내 문구 | String | — | 정적 |

### 입력 데이터
| 행위 | 항목 | 타입 | 필수 | 검증 |
|------|------|------|------|------|
| 검색 submit | keyword | String | Y | 1자 이상 |
| 필터 | type | enum | N | ALL/SCHEDULE/MEMO, 기본 ALL |
| 필터 | tagIds | List&lt;Long&gt; | N | 본인 소유 태그 |
| 페이징 | page | Integer | N | 기본 0 |
| 페이징 | size | Integer | N | 기본 20, 최대 100 |

### 데이터 조합 요구
- 검색: `schedule`(+`schedule_tag`) ∪ `memo`(+`memo_tag`) 두 결과 합쳐 시간 역순 정렬(일정은 `start_at`, 메모는 `updated_at`) + Pagination 공통 적용
- TagPicker 옵션 로드: `tag` (본인)
- 시간 역순 정렬의 "시간"은 **일정=start_at, 메모=updated_at** — /session11 확정
→ 최소 API 2개: `GET /api/search?q=&type=&tagIds=&page=&size=`, `GET /api/tags` (옵션 로드)
★ 교차 모듈: 태그 모듈이 일정/메모 검색 결과 렌더링에 필요

## S103: 일정 상세 · 수정

| 영역 | 항목 | 타입 | 출처 | 비고 |
|------|------|------|------|------|
| 헤더 | 제목 | String | `schedule.title` | |
| 헤더 | 반복 Badge | boolean | `schedule.repeat_rule ≠ NONE` | 계산값 |
| 좌측 본문 | 시작/종료 시각 | DateTime×2 | `schedule.start_at`, `schedule.end_at` | |
| 좌측 본문 | 장소 | String | `schedule.location` | |
| 좌측 본문 | 반복 규칙 | enum | `schedule.repeat_rule` | |

| 우측 패널 | 붙은 메모 목록(요약) | List&lt;MemoSummary&gt; | `schedule_memo_link` JOIN `memo` ★ | 연결+메모 모듈 |
| 우측 패널 | 연결 링크 id (해제용) | Long | `schedule_memo_link.id` ★ | 연결 모듈 |
| Modal(삭제 확인) | 고정 문구 | String | — | 정적 |
| Toast | 성공/에러 메시지 | String | — | 정적 |

### 입력 데이터
| 행위 | 항목 | 타입 | 필수 | 검증 |
|------|------|------|------|------|
| 수정 | title | String | Y | 1~200 |
| 수정 | startAt | DateTime | Y | |
| 수정 | endAt | DateTime | Y | ≥ startAt (AUTH-독립 SCHED-4000) |
| 수정 | location | String | N | ≤ 200 |
| 수정 | repeatRule | enum | N | NONE/DAILY/WEEKLY/MONTHLY |
| 수정 | remindBeforeMinutes | int | N | 0~1440, 기본 30 |
| 수정 | tagIds | List&lt;Long&gt; | N | 본인 소유 |
| 업로드 | file | binary | Y | 확장자(jpg/jpeg/png/gif/pdf), ≤10MB, 건당 ≤5개 |
| 연결 해제 | linkId | Long | Y | |

### 데이터 조합 요구
- `schedule` (자기) + `schedule_tag`+`tag` (태그 모듈) ★ + `attachment` (첨부 모듈) ★ + `schedule_memo_link`+`memo` (연결+메모 모듈) ★
- API 분할 방식 (/session11 확정 예정):
  - `GET /api/schedules/:id` → 일정 본체 + 태그 id/이름 포함 (해당 owner 태그 JOIN)
  - `GET /api/schedules/:id/attachments` → 첨부 목록
  - `GET /api/schedules/:id/linked-memos` → 연결된 메모 요약 목록 (linkId 포함)
→ 최소 API 3개 (상세 로드 시)
★ 교차 모듈: 태그·첨부·연결(+메모)
