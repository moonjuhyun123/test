# 요구사항명세서

## 프로젝트 개요
- 프로젝트명: 캘린더
- 한 줄 설명: 일정에 메모를 붙이고, 메모에 일정을 붙이는 개인 일정·메모 연동 도구
- 유형: 신규 개발

## 사용자 유형
| 유형 | 설명 | 주요 행위 |
|------|------|----------|
| 일반 사용자 | 본인의 일정과 메모를 관리하는 싱글 유저 | 일정·메모 생성/조회/수정/삭제, 일정↔메모 연결, 검색, 알림 수신 |

## 기능별 상세

### F001: 로그인

**사용자 시나리오**: 사용자가 ID/PW를 입력해 로그인한다. 로그인 성공 시 JWT를 발급받아 이후 요청에 사용한다.

**전제 조건**: 사용자 계정이 존재한다.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| id | string | Y | 로그인 ID |
| password | string | Y | 비밀번호 |

**시스템 반응**: 인증 성공 시 JWT 토큰을 반환하고 메인 캘린더 화면으로 이동한다.

**후속 행위**: 이후 모든 API 요청에 JWT 사용.

**예외/복구**: ID/PW 불일치 시 에러 메시지 표시, 재입력 유도.

**알림/연동**: 없음.

**외부 연동**: 없음.

---

### F002: 일정 생성·조회·수정·삭제

**사용자 시나리오**: 캘린더 월/주 뷰에서 날짜·시간을 선택해 일정(제목, 시작/종료, 장소, 반복, 태그, 알림 설정)을 만든다. 기존 일정은 클릭해 상세를 보고 수정·삭제할 수 있다.

**전제 조건**: 로그인되어 있어야 한다.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| title | string | Y | 일정 제목 |
| startAt | datetime | Y | 시작 시각 |
| endAt | datetime | Y | 종료 시각 |
| location | string | N | 장소 |
| repeatRule | enum | N | NONE / DAILY / WEEKLY / MONTHLY |
| tags | string[] | N | 태그 목록 |
| remindBeforeMinutes | int | N | 시작 전 알림 분 (기본 30) |

**시스템 반응**: 생성/수정 후 캘린더 뷰에 즉시 반영. 삭제 시 연결된 메모는 유지하고 연결 링크만 끊는다.

**후속 행위**: F004(메모 붙이기), F007(알림) 후보가 된다.

**예외/복구**: 시작>종료면 에러. 삭제는 되돌릴 수 없음 (확인 다이얼로그).

**알림/연동**: F007에서 발송.

**외부 연동**: 없음.

---

### F003: 메모 생성·조회·수정·삭제

**사용자 시나리오**: 메모 목록에서 새 메모를 만든다. 제목, 본문(마크다운 — 텍스트 + 체크박스 + 이미지 인라인), 태그, 첨부를 입력한다. 메모 상세에서 연결된 일정 목록을 본다.

**전제 조건**: 로그인되어 있어야 한다.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| title | string | Y | 메모 제목 |
| body | string (markdown) | N | 본문 (텍스트/체크박스/이미지 인라인) |
| tags | string[] | N | 태그 목록 |
| attachments | file[] | N | 첨부 파일 |

**시스템 반응**: 생성/수정 후 메모 목록 최상단에 반영. 삭제 시 연결된 일정의 링크만 끊고 일정은 유지한다.

**후속 행위**: F005(메모에서 일정 만들기) 진입 가능.

**예외/복구**: 첨부 제한 초과 시 에러. 삭제는 되돌릴 수 없음.

**알림/연동**: 없음.

**외부 연동**: 없음.

---

### F004: 일정에 메모 붙이기

**사용자 시나리오**: 일정 상세를 열면 우측 패널에 "붙은 메모 목록"이 있다. 새 메모를 작성해 붙이거나 기존 메모를 연결한다. 한 일정에 메모 여러 개를 붙일 수 있다.

**전제 조건**: 일정이 존재한다.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| scheduleId | long | Y | 대상 일정 ID |
| memoId | long | Y | 연결할 메모 ID (신규 생성 후 사용 가능) |

**시스템 반응**: 일정 상세의 메모 목록에 즉시 추가. 해당 메모의 "연결된 일정" 목록에도 자동 반영(양방향).

**후속 행위**: 당일 일정 열람 시 해당 메모를 그대로 본다.

**예외/복구**: 이미 연결된 메모 재연결 시 무시. 연결 해제 시 양쪽에서 링크만 끊기고 데이터는 유지.

**알림/연동**: 없음.

**외부 연동**: 없음.

---

### F005: 메모에서 일정 만들기

**사용자 시나리오**: 메모 작성 중 "이건 다음 주까지 해야겠다" 싶으면 메모 상세에서 "일정 만들기" 버튼을 누른다. 일정 생성 폼이 뜨고, 저장하면 원본 메모와 새 일정이 양방향 연결된 채로 남는다.

**전제 조건**: 원본 메모가 존재한다.

**입력 항목**: F002의 일정 입력 항목 + `sourceMemoId` (원본 메모 ID)

**시스템 반응**: 일정 생성 + 원본 메모에 자동 연결.

**후속 행위**: 일정·메모 양쪽에서 서로를 조회 가능.

**예외/복구**: 일정 생성 실패 시 연결도 생성되지 않음 (트랜잭션).

**알림/연동**: 없음.

**외부 연동**: 없음.

---

### F006: 통합 검색

**사용자 시나리오**: 검색창에 키워드를 입력하면 일정(제목·장소) + 메모(제목·본문)에서 함께 검색되어 결과가 섞여 나온다. 결과를 클릭하면 해당 일정/메모 상세로 이동.

**전제 조건**: 로그인되어 있어야 한다.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| keyword | string | Y | 검색어 |
| type | enum | N | ALL / SCHEDULE / MEMO (기본 ALL) |
| tags | string[] | N | 태그 필터 |

**시스템 반응**: 일정·메모 결과를 한 목록에 시간 역순으로 표시.

**후속 행위**: 결과 클릭 시 해당 상세 화면.

**예외/복구**: 결과 없으면 빈 목록 표시.

**알림/연동**: 없음.

**외부 연동**: 없음.

---

### F007: 일정 시작 알림

**사용자 시나리오**: 일정 시작 N분 전(기본 30분)에 SSE로 브라우저에 알림이 푸시된다. 알림에서 바로 붙어있는 메모 목록을 펼쳐 볼 수 있다.

**전제 조건**: 사용자가 로그인한 세션에서 SSE 연결이 열려 있어야 한다.

**입력 항목**: (F002의 `remindBeforeMinutes` 설정을 따름)

**시스템 반응**: SSE 이벤트로 일정 정보 + 연결된 메모 요약을 전송. 브라우저에서 토스트/패널로 표시.

**후속 행위**: 알림에서 일정 상세로 진입 가능.

**예외/복구**: SSE 연결 끊김 시 재접속 후 누락 알림은 표시하지 않음 (실시간만).

**알림/연동**: 내부 SSE 채널.

**외부 연동**: 없음.

---

### F008: 일정 반복

**사용자 시나리오**: 일정 생성/수정 시 반복 규칙(매일/매주/매월)을 선택하면 이후 일정이 반복 생성된다.

**전제 조건**: 일정 생성·수정 흐름 내.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| repeatRule | enum | N | NONE / DAILY / WEEKLY / MONTHLY |

**시스템 반응**: 캘린더 뷰에 반복 일정이 표시됨.

**후속 행위**: 개별 회차 수정/삭제 (상세 규칙은 세션 9에서 정의).

**예외/복구**: 세부 엣지케이스(종일 타임존 등)는 제외 범위.

**알림/연동**: F007 규칙 동일.

**외부 연동**: 없음.

---

### F009: 태그

**사용자 시나리오**: 일정·메모에 `#회의`, `#아이디어` 같은 태그를 붙인다. 태그는 3단계 계층 구조를 가질 수 있다(예: `업무 > 회의 > 기획리뷰`). 태그로 묶어 필터링/조회한다.

**전제 조건**: 없음.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| name | string | Y | 태그명 |
| parentId | long | N | 상위 태그 ID (최대 3단계) |

**시스템 반응**: 태그 관리 화면에서 생성/수정/삭제. 필터 UI에 계층 트리 표시.

**후속 행위**: F006(검색)에서 태그 필터와 결합.

**예외/복구**: 4단계 이상 중첩 시 에러. 태그 삭제 시 연결된 일정·메모의 태그만 해제.

**알림/연동**: 없음.

**외부 연동**: 없음.

---

### F010: 체크리스트

**사용자 시나리오**: 메모 본문에 체크박스 마크다운(`- [ ]`, `- [x]`)을 사용해 할 일을 관리한다.

**전제 조건**: 메모 본문 편집 중.

**입력 항목**: 메모 body 내 체크박스 마크다운.

**시스템 반응**: 렌더링 시 체크박스 UI로 표시, 클릭으로 토글되어 본문이 자동 저장됨.

**후속 행위**: 메모 수정 이력.

**예외/복구**: 없음.

**알림/연동**: 없음.

**외부 연동**: 없음.

---

### F011: 첨부 파일

**사용자 시나리오**: 일정/메모 상세에서 파일을 업로드한다. 파일당 최대 10MB, 건당 최대 5개, 이미지(jpg/jpeg/png/gif) + PDF만 허용.

**전제 조건**: 일정/메모 상세 화면.

**입력 항목**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|------|------|
| file | binary | Y | 업로드 파일 |

**시스템 반응**: 업로드 후 일정/메모 상세에 썸네일/파일명 표시. 클릭 시 미리보기/다운로드.

**후속 행위**: 일정/메모 삭제 시 첨부도 삭제.

**예외/복구**: 용량/개수/확장자 초과 시 에러 메시지.

**알림/연동**: 없음.

**외부 연동**: 없음 (내부 파일 스토리지 사용).

## MVP 범위

### 필수 (이것 없으면 업무 멈춤)
- F001 로그인
- F002 일정 생성·조회·수정·삭제
- F003 메모 생성·조회·수정·삭제
- F004 일정에 메모 붙이기
- F005 메모에서 일정 만들기
- F006 통합 검색
- F007 일정 시작 알림 (SSE)

### 후순위 (없어도 대체 수단 있음)
- F008 일정 반복
- F009 태그 (계층 3단계)
- F010 체크리스트
- F011 첨부 파일

### 제외 (파일럿에서 만들지 않음)
- 구글 캘린더 연동 (외부 API 불가 환경)
- 공유·협업 (싱글 유저)
- 모바일 앱 (웹만)
- 음성 입력, AI 요약
- 구글 외 캘린더 (아웃룩/애플 등)
- 종일 일정 타임존 세밀 처리

## 환경/제약
- 접속 환경: PC 웹 브라우저 (내부망)
- 동시 사용자: 1명 (싱글 유저)
- 외부 접속: 없음
- 연동 시스템: 없음
- 보안 요구: 별도 요구사항 없음

## 기술 스택 (확정된 것만)
- 백엔드: Java 17+ / Spring Boot 3.x (JPA)
- DB: H2 2.x (개발용)
- 프론트: React 18+ + TypeScript
- 인증: JWT
- 기타: 단일 서버 배포, SSE 기반 실시간 알림
