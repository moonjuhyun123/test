# API 테스트 케이스

기준 입력: 11_API_스펙.md, 06_공통_구조_설계서.md

유형 범례: **S**=성공, **V**=검증 실패, **N**=리소스 없음/소유 불일치, **A**=권한/인증, **C**=충돌/멱등, **B**=경계/기타
