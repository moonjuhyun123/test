## 화면 흐름도

### 로그인·진입
S001(로그인) → S101(캘린더 월 뷰) : 인증 성공 시
S001(로그인) → S001 : 인증 실패 시 에러 메시지 후 재입력
(무인증 요청 시) 전 화면 → S001 : 토큰 없음/만료

### 일정
S101(월 뷰) → S102(주 뷰) : 뷰 전환 토글
S101/S102 → S103(일정 상세) : 일정 칩 클릭
S101/S102 → S104(일정 생성) : 날짜·시간 셀 클릭 또는 "일정 만들기" 버튼
S104 → S103 : 저장 성공 후 (또는 S101로 복귀)
S103 → S103 : 수정 저장 (같은 화면 갱신)
S103 → S101 : 삭제 확인 후 캘린더로 복귀

### 메모
S201(메모 목록) → S202(메모 상세) : 메모 항목 클릭
S201 → S203(메모 생성) : "새 메모" 버튼
S203 → S202 : 저장 성공 후
S202 → S202 : 수정 저장
S202 → S201 : 삭제 확인 후 목록으로 복귀

### 연결 (F004·F005) — 기존 화면 내 인터랙션
S103(일정 상세) → S203 : 우측 "메모 붙이기 (새 메모)" 버튼 → 생성 후 자동 연결되어 S103 복귀
S103(일정 상세) → S201(선택 모드) : "기존 메모 붙이기" 버튼 → 선택 후 S103 복귀
S202(메모 상세) → S104(일정 생성, `sourceMemoId` 주입) : "일정 만들기" 버튼 → 저장 후 S202 복귀 (양방향 연결 유지)

### 검색
메인 셸 검색창 → S003(검색 결과) : 키워드 입력 + 엔터
S003 → S103 : 일정 결과 클릭
S003 → S202 : 메모 결과 클릭

### 태그 (후순위)
사이드바 "태그 관리" → S301
S301 → S301 : 태그 생성/수정/삭제 후 같은 화면 갱신
S101/S201/S003 → 태그 필터 적용 (각 화면 내 필터, 별도 이동 없음)

### 알림
(백그라운드 SSE) → S401 토스트 : 일정 시작 N분 전 이벤트 수신
S401 → S103 : 토스트/패널 항목 클릭 → 해당 일정 상세로 이동

### 전체 흐름 요약
S001(로그인) → S101(캘린더 월 뷰, 메인) → {
  S102(주 뷰) ·
  S103(일정 상세) ↔ S104(일정 생성) ·
  S201(메모 목록) → S202(메모 상세) ↔ S203(메모 생성) ·
  S003(통합 검색) ·
  S301(태그 관리) ·
  S401(알림 패널/토스트)
}
