# 11 API 설계 분할 계획

## 도메인 수 및 의존 관계 (04 기준)
8 도메인: 사용자/인증, 일정, 메모, 연결, 태그, 첨부, 검색, 알림

의존 방향(04 단방향 정리 결과):
```
사용자/인증 (루트)
  ├─ 일정     ← 연결/태그/첨부/검색/알림
  ├─ 메모     ← 연결/태그/첨부/검색/알림
  ├─ 연결(ScheduleReader, MemoReader 소비)  ← 알림
  ├─ 태그(ScheduleReader, MemoReader 소비)
  ├─ 첨부(ScheduleReader, MemoReader 소비)
  ├─ 검색 (순수 소비자)
  └─ 알림 (순수 소비자)
```

## 분할 정책
- 자동 일괄 실행(autonomous run) — 1 세션에서 전부 설계
- 설계 순서(하위 → 상위):
  1. 사용자/인증
  2. 일정
  3. 메모
  4. 연결
  5. 태그
  6. 첨부
  7. 검색
  8. 알림
