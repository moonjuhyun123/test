   - 기대 효과: 02~13에서 "로그아웃" 5회 반복 언급 제거

2. **session2 템플릿에 "도메인·모듈 네이밍 확정 컬럼" 추가**

   - 개선: 각 도메인마다 "영문 모듈명 후보(여러 개) — 최종 1개 확정" 필수. 16까지 끌고 가지 않음
   - 기대 효과: 16에서 네이밍 결정 소요 제거

3. **session3 템플릿에 "FK 삭제 정책 4지선다" 필수 필드**
   - 현재: 각 FK의 ON DELETE 정책 유예 허용
   - 개선: CASCADE / RESTRICT / SET NULL / 앱 레벨 중 1개 명시 — 이유 포함
   - 기대 효과: 14에서 7개 FK 정책 결정 소요 → 03에서 선제 결정
