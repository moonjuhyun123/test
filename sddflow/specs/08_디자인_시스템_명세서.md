# 디자인 시스템 명세서

기준 입력: PROJECT_CONTEXT.md (React 18+ TS, 내부망 PC 웹), 07_화면목록.md (S001~S401)

사용자 인터뷰 부재로 기본값 채택. 내부망 업무 도구(싱글 유저)의 관례적 기본을 적용하고, 이후 재검토가 쉽도록 토큰 중심으로 설계.

## 공통 컴포넌트

07에서 등장하는 UI 필요 요소만 도출. 각 컴포넌트는 shadcn/ui 또는 Radix UI 스타일의 headless 기반으로 구현 가능 (구현 선택은 /build-design-system에서 확정).

### Button
- Variants: `primary`, `secondary`(outline), `ghost`, `danger`
- Sizes: `sm`(28px), `md`(36px, 기본), `lg`(44px)
- Props: `variant`, `size`, `disabled`, `loading`, `leftIcon?`, `rightIcon?`, `fullWidth?`
- 상태: default / hover / active / focus(ring) / disabled / loading

### IconButton
- 아이콘 전용 정사각형 버튼. size `sm`(28) / `md`(36). Tooltip 동반 필수.
- 사용: 헤더(알림 벨), 캘린더 셀 + 버튼, 메모 목록 액션 등.

### Input (TextField)
- Types: `text`, `password`, `search`
- Props: `label`, `value`, `onChange`, `placeholder`, `error?`, `hint?`, `disabled`, `required`, `leftIcon?`, `rightIcon?`, `maxLength?`
- 상태: default / focus / error / disabled / readonly

### Textarea
- 마크다운 본문(S203 F003) + 장소/제목 보조.
- Props: `value`, `onChange`, `rows`, `autoResize`, `error?`, `hint?`, `maxLength?`

### Select (SingleSelect)
- 반복 규칙(NONE/DAILY/WEEKLY/MONTHLY), 검색 타입(ALL/SCHEDULE/MEMO) 등.
- Props: `options: {value, label}[]`, `value`, `onChange`, `placeholder`, `disabled`, `error?`

### MultiSelect / TagPicker
- 태그 다중 선택(S104, S203) + 태그 생성 인라인.
- Props: `options: TagOption[]`, `value: TagOption[]`, `onChange`, `allowCreate`, `maxDepth=3`(태그 계층)

### DateTimePicker
- 일정 시작/종료 시각(S104). 캘린더 인라인 + 시간 드롭다운.
- Props: `value`, `onChange`, `min?`, `max?`, `step=15min`, `error?`

### NumberInput
- 알림 분(remindBeforeMinutes, 기본 30).
- Props: `value`, `onChange`, `min=0`, `max=1440`, `step=5`

### Checkbox
- 메모 본문 체크박스(F010 인라인) + 목록 선택 등.
- Props: `checked`, `onChange`, `label?`, `disabled`

### Radio / RadioGroup
- 검색 타입 필터(옵션 수 적을 때 대체 UI).
- Props: `name`, `options`, `value`, `onChange`

### Toggle / Switch
- 향후 "알림 on/off" 등 확장 슬롯. **07 근거 없음** → 본 버전에서 **제외**.

### Button 이외 액션 요소

#### Dropdown Menu
- S002 헤더 사용자 메뉴(프로필 이니셜 → 로그아웃 후보) / 일정·메모 상세의 "⋯" 액션.
- Props: `trigger`, `items: MenuItem[]`, `align`

#### Modal / Dialog
- 삭제 확인 다이얼로그(01 F002/F003 "확인 다이얼로그"), 태그 관리 편집.
- Props: `open`, `onClose`, `title`, `footer?`, `size=sm|md|lg`
- 상태: open / closing / closed

#### Toast / Alert
- F007 실시간 알림(정보 토스트) + 저장 완료·에러 피드백.
- Props: `variant=info|success|warning|error`, `title`, `description?`, `duration=5000ms`, `action?`
- 위치: 우측 상단 스택. 최대 3개 동시 표시, 초과 시 대체.

#### Popover / Tooltip
- 캘린더 셀 hover 시 일정 요약, IconButton 힌트.
- Props: `content`, `placement`, `trigger=hover|click`

### 표시 컴포넌트

#### Card
- 메모 목록 카드(S201), 알림 패널 항목(S401).
- Props: `children`, `onClick?`, `selected?`, `elevation=0|1|2`

#### List / ListItem
- 메모 목록, 검색 결과, 일정-메모 연결 목록.
- Props: `items`, `renderItem`, `onItemClick?`, `emptyState?`

#### Badge / Tag (Chip)
- 태그 표시(F009), 상태 뱃지(예: 반복 일정 표시 `R`).
- Variants: `solid`, `subtle`, `outline`
- Sizes: `sm`(20px), `md`(24px)
- Tag 전용 Props: `color?`(태그 색상, 기본 neutral), `onRemove?`(입력 필드 내부 태그 제거)

#### Avatar
- S002 헤더 사용자 프로필(이니셜). 싱글 유저이므로 기본 단일 사이즈.

#### Divider
- 섹션 구분. `orientation=horizontal|vertical`

#### Pagination
- 목록 페이지 이동. S003 검색 결과, S201 메모 목록.
- Props: `page: number`(0-base), `size: number`, `totalPages: number`, `onChange(page: number) => void`, `boundary=1`, `sibling=1`
- 상태: default / current / disabled
- 빈 상태(totalPages=0)에서는 렌더하지 않음.

#### Tabs (SegmentedControl)
- 제한된 선택지 전환. S101/S102 월/주 뷰 토글.
- Props: `items: {value, label}[]`, `value`, `onChange(value) => void`, `size=sm|md`
- 동작: 값 변경만 하며 라우팅은 호출측 책임.

#### Skeleton
- 로딩 상태(목록·상세 초기 로딩).

#### EmptyState
- Props: `icon`, `title`, `description`, `action?`
- 용도: S003 "검색 결과 없음", S201 "메모 없음", S103 우측 "붙은 메모 없음"

#### ErrorState
- Props: `title`, `description`, `retry?`
- 용도: API 실패, SSE 끊김 복구 실패(01 F007 "실시간만", 단순 아이콘 + 안내)

### 특수 컴포넌트 (07 근거로만 생성)

#### CalendarGrid (MonthView / WeekView)
- S101, S102 전용. 월 그리드 7×N + 주 타임라인 뷰.
- Props: `month` or `weekStart`, `events: ScheduleSummary[]`, `onCellClick`, `onEventClick`
- 상태: loading / ready / error

#### ScheduleEventChip
- 캘린더 셀 내부 일정 표시. 길이·색·반복 뱃지 포함.
- Props: `title`, `startAt`, `endAt`, `isRepeat`, `onClick`

#### MarkdownEditor
- S202/S203 메모 본문. 텍스트 + 체크박스 + 이미지 인라인(F010, F011).
- Props: `value`, `onChange`, `placeholder`, `onUpload?(file)` → 첨부 인라인.
- **의존성**: 경량 WYSIWYG or plain textarea + preview 토글. 서드파티 선택은 /build-design-system에서.

#### MarkdownRenderer
- S202 본문 표시(읽기 모드). 체크박스 토글 시 `onChange` 호출.

#### FileUploader
- F011 첨부. 드래그앤드롭 + 파일 선택. 제한: 이미지(jpg/jpeg/png/gif) + PDF, ≤10MB, ≤5개.
- Props: `value: AttachmentItem[]`, `onAdd`, `onRemove`, `maxCount=5`, `maxSizeBytes=10*1024*1024`, `accept`
- 상태 표시: 업로드 중 / 성공 / 실패 / 한도 초과

#### SearchBar
- S002 헤더. 검색창 + 최근 검색어(선택) + 엔터 시 S003 이동.
- Props: `value`, `onChange`, `onSubmit`, `placeholder`

#### NotificationToast (F007 전용)
- 일정 알림용 확장 Toast. 연결된 메모 목록 펼치기 가능.
- Props: `schedule: ScheduleSummary`, `linkedMemos: MemoSummary[]`, `onOpenSchedule`

#### TagTreeEditor (S301)
- 3단계 계층 태그 CRUD 트리.
- Props: `tags: TagSummary[]`, `onCreate`, `onRename`, `onDelete`, `onMove`
