# /session17 — 외부 연동 확인 리스트 생성 (설계 완료 후)

## 역할
너는 Integration Lead다. 설계 산출물 전체를 스캔해 외부 시스템 어댑터가 실제 필요로 하는 필드·동작을 역산하고, 사용자가 내부망에서 확인할 체크리스트를 만든다.

## 용도
세션1에서는 외부 시스템 이름·용도·필수여부만 받았고, 세션5에서는 포트 인터페이스 껍데기만 만들었다. 이 세션이 설계 전체를 스캔해서 TBD 필드를 채울 근거를 뽑는다.

## 실행 시점
세션16(MODULE_SPEC + FRONT_SPEC) 완료 후, 개발 시작 게이트 직전. 백엔드 구현(`/implement-{모듈}`) 시작 전에 반드시 실행한다.

## 입력
1. `specs/01_요구사항명세서.md` — 외부 연동 목록
2. `specs/05_공용_인터페이스_명세.md` — 포트 목록과 위임 범위
3. `specs/09_화면_상세_명세서.md` — 화면이 표시하는 데이터
4. `specs/10_표시_데이터.md` — 필드 단위 표시 규칙
5. `specs/11_API_스펙.md` — API 응답 DTO
6. `specs/13_화면_API_매핑.md` — 어떤 화면이 어떤 데이터를 쓰는지
7. `specs/modules/*` — 모듈별 어댑터 사용 지점

## 할 일

1. 05의 "외부 연동 어댑터 포트" 각 포트마다:
   - 해당 포트가 호출되는 지점을 전체 코드·명세에서 찾음
   - 호출 측이 **실제로 사용하는 필드·동작**을 역산
   - TBD로 남아 있던 DTO 필드를 "필요한 필드 후보 목록"으로 구체화
2. 각 포트에 대해 **"없음 대처 경로"**를 명시
3. 담당자 찾기는 하지 않는다. 사용자가 내부망에서 알아서 찾는다.

## 출력 형식
```markdown
# 외부 연동 확인 리스트

- 생성 시점: {타임스탬프}
- 기준 산출물: 01, 05, 09, 10, 11, 13

## {외부 시스템명 1} (예: 사내 SSO)

**위임 범위**: {세션5에서 확정한 최소 책임. 예: 사번/비번 검증만}

**확인할 항목**:
- [ ] {질문 1}. 예: 사번·비밀번호 검증 API 존재 여부
- [ ] {질문 2}. 예: 실패 응답 형식(잠김/비번 오류/퇴사자 구분 가능?)
- [ ] {질문 3}. 예: 세션 유지 기본값

**설계에서 역산한 필요 필드** (포트 DTO가 반환해야 할 것):
| 필드 | 타입 | 출처 파일 | 출처 위치(섹션/행) | 사용 코드 근거 | 필수/선택 |
|------|------|----------|-------------------|--------------|----------|
| 인증 결과(성공/실패) | boolean | 09_화면_상세_명세서.md | F001 로그인 화면 | "로그인 버튼 클릭 → 성공 시 메인, 실패 시 에러" | 필수 |
| 실패 사유 코드 | string | 09_화면_상세_명세서.md | F001 에러 표시 규칙 | "비번 오류/잠김/퇴사자 구분 표시" | 필수 |

- **출처 인용이 없는 필드는 적지 마라.** 추측 금지. 설계 산출물에서 근거를 못 찾으면 해당 필드는 포함하지 않는다.

**없음 대처 경로**:
- API 자체가 없음 → 세션5로 돌아가 자체 구현(내부 DB + 해시)으로 전환
- 필드 일부만 제공 → 세션1 해당 기능 재검토 or 대체 어댑터 추가
- 제약 있음(예: 주민번호 미제공) → 세션1 요구사항 조정
- 답변 지연 → Stub으로 진행, 실제 어댑터는 내부망에서 추후 연결

---

## {외부 시스템명 2}
...

## 요약
- 외부 시스템 수: {N}
- 확인 항목 총 {M}건
- TBD → 구체화된 포트 DTO 수: {K}/{N}
```

## 출력 파일
`specs/17_외부연동_확인리스트.md`로 저장.

## 자체 검증
- 05에 등록된 외부 어댑터 포트 수와 이 문서의 시스템 수가 일치하는가
- 각 시스템에 "위임 범위 / 확인 항목 / 필요 필드 / 없음 대처 경로" 4개 섹션이 모두 있는가
- **필요 필드의 모든 항목이 "출처 파일·출처 위치·사용 코드 근거"를 갖는가** (하나라도 비면 자가 ❌)
- 출처로 인용된 파일·위치가 실제로 존재하는지 확인 (grep 가능해야 함)

## 사용자 안내
이 파일이 생성되면 사용자에게 다음 메시지를 출력:
```
외부 연동 확인 리스트가 생성되었습니다: specs/17_외부연동_확인리스트.md
이 파일의 체크리스트를 들고 내부망에서 확인하세요.
확인 결과를 05_공용_인터페이스_명세.md의 해당 포트 DTO에 반영한 뒤
`/implement-{모듈}`로 구현을 진행하면 됩니다.
답변이 지연되면 Stub 상태로 진행 가능하며, 실제 어댑터는 내부망에서 나중에 연결합니다.
```

## 절대 규칙
- 담당자·연락처·계약 자료 위치를 찾거나 묻지 마라. 사용자가 내부망에서 처리.
- 추측으로 필드를 채우지 마라. 설계 산출물에서 역산된 근거가 있는 필드만 적어라.
- 외부 의존 최소화 원칙(헌법) 준수. 포트가 광범위한 책임을 갖고 있으면 "위임 범위 축소 + 내부로 흡수" 제안을 함께 기록.
- "없음 대처 경로"는 반드시 4가지 경우(없음/일부만/제약/지연) 모두 명시.
