# /review-03 — ERD 초안 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/02_도메인_분류.md (기준)
2. specs/03_ERD.md (검증 대상)

## 검증 항목
1. 도메인 분류의 모든 도메인에 테이블이 있는가
2. 도메인별 각 행위에 필요한 데이터가 ERD 컬럼으로 존재하는가
3. 도메인 분류에 없는데 ERD에만 있는 테이블 (AI 추가) — 단, 권한 모델 필수 테이블은 예외
4. FK 방향이 논리적인가 (부모 → 자식)
5. 상태값이 필요한 테이블에 상태 컬럼이 있는가
6. PK 전략이 일관적인가
7. **권한 모델에 맞는 필수 테이블/컬럼이 있는가** (PROJECT_CONTEXT의 권한 모델 기준):
   - Simple Role: `user.role` enum 컬럼
   - RBAC 정적: `user_role` 매핑 테이블
   - RBAC 동적: `role`, `permission`, `role_permission`, `user_role` 전부
   - 계층형 RBAC: `role.parent_id` 자기참조
   - RBAC + 소유자/조직: 모든 리소스 테이블에 `owner_id` 또는 `org_id`
