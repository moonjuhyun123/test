# /review-08 — 디자인 시스템 명세 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/07_화면목록.md (기준)
2. specs/08_디자인_시스템_명세서.md (검증 대상)

둘 다 처음부터 읽어라.

## 검증 항목
1. 화면 목록에서 필요한 컴포넌트가 디자인 시스템에 모두 포함되었는가
2. 화면 목록에 근거 없는 컴포넌트가 추가되지 않았는가 (AI 추가)
3. 각 컴포넌트에 Props가 정의되어 있는가
4. Props에 any 타입이 사용되지 않았는가
5. 디자인 토큰(색상, 타이포, 간격)이 정의되어 있는가
6. 레이아웃 구조가 정의되어 있는가
7. 상태 표시용 컴포넌트(EmptyState, ErrorState, Loading)가 포함되어 있는가

## 결과 저장
specs/_reviews/08_review.md

## 출력 형식
```markdown
# 리뷰: 08_디자인_시스템_명세서.md
- 일시: {타임스탬프}

## Props 정의 검증
| 컴포넌트 | Props 정의 | any 사용 | 상태 |
|----------|-----------|---------|------|

## 필수 항목 체크
| 항목 | 존재 |
|------|------|
| 색상 체계 | ✅/❌ |
| 타이포그래피 | ✅/❌ |
| 간격 체계 | ✅/❌ |
| 레이아웃 구조 | ✅/❌ |

## 수치
- 컴포넌트 수: {N}개

## 판단
✅ 다음 진행 가능 / ❌ 수정 필요 ({사유})
```
