# /review-15 — CLAUDE.md 법률 섹션 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/ 폴더 전체 (기준 — 특히 06, 11)
2. CLAUDE.md (검증 대상)

## 검증 항목
1. 헌법 섹션이 손상되지 않았는가 (원본과 동일한가)
2. 법률 섹션에 플레이스홀더({...})가 남아있지 않은가
3. 기술 스택이 specs/ 내용과 일치하는가
4. 에러 코드 규칙이 06_공통_구조_설계서와 일치하는가
5. 날짜/페이징/빈 목록 규칙이 11_API_스펙과 일치하는가
6. 확정 범위(MVP 기능 + 모듈 목록)가 채워졌는가
7. **패키지 구조 > 공통 모듈 서브패키지가 모두 채워졌는가** (빈 값 금지)
8. **패키지 구조의 서브패키지 이름에 Java 예약어가 없는가**
9. **"권한 체크 규칙" 섹션이 모두 채워졌는가**: 권한 모델 / 체크 위치 / 역할 검사 패턴 / 소유자·조직 검사 위치 / Stub 동작 / 권한 에러 코드 / 권한 예외 클래스 / 중복 검사 금지 명시 — 하나라도 비면 ❌
10. **법률의 권한 모델이 PROJECT_CONTEXT·specs/05·specs/06 값과 일치하는가** (불일치 시 어느 쪽이 옳은지 보고)
11. **01_요구사항명세서에 "외부 연동 - 필수"가 있으면 법률에 "외부 연동 어댑터 규칙" 섹션이 있는가** — 없거나 필수 어댑터 표가 비면 ❌
12. **법률의 필수 어댑터 목록이 specs/modules/*의 "필수 외부 연동 어댑터" 집계와 일치하는가** (불일치 시 보고)

## 결과 저장
specs/_reviews/15_review.md

```markdown
# 리뷰: CLAUDE.md (법률 섹션)

- 손상 여부: ✅ 정상 / ❌ 변경됨

## 법률 항목
| 항목 | 채워짐? | specs/와 일치? |

## 공통 모듈 서브패키지 (세부 검증)
| 서브패키지 | 채워진 값 | 예약어 위반 |

## 플레이스홀더 잔존
- {있으면 목록}

## 판단
✅ / ❌
```

## 절대 규칙
- 검증만 해라. CLAUDE.md를 수정하지 마라.
- **공통 모듈 서브패키지 중 하나라도 비어 있으면 판단은 ❌다.**
- **서브패키지 이름에 Java 예약어가 1건이라도 있으면 판단은 ❌다.**
- **"권한 체크 규칙" 섹션의 항목 중 하나라도 비어 있거나 specs/와 불일치하면 판단은 ❌다.**
- **01에 "외부 연동 - 필수"가 있는데 법률에 "외부 연동 어댑터 규칙" 섹션이 없거나 표가 비면 판단은 ❌다.**
