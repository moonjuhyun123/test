# /review-04 — 도메인 분리 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/03_ERD.md (기준)
2. specs/04_도메인_분리.md (검증 대상)

## 검증 항목
1. ERD의 모든 테이블이 어떤 모듈에 배정됐는가
2. 배정 안 된 테이블 목록
3. 양방향 의존 존재 여부 (A→B, B→A) — 있으면 ❌
4. 하나의 테이블이 여러 모듈에 중복 배정되지 않았는가 (공용 테이블 제외)
5. 컨텍스트 크기 추정이 현실적인가 (테이블 10개 이상이면 "대")

## 결과 저장
specs/_reviews/04_review.md

## 출력 형식
```markdown
# 리뷰: 04_도메인_분리.md
- 기준: 03_ERD.md

## 테이블 배정
| 테이블 | 배정 모듈 | 상태 |

## 양방향 의존
| 모듈 A → 모듈 B | 모듈 B → 모듈 A | 순환? |

## 수치
- 배정률: {N}/{M} ({%})
- 양방향 의존: {N}건

✅ / ❌
```
