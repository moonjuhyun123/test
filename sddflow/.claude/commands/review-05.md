# /review-05 — 공용 인터페이스 명세 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/04_도메인_분리.md (기준 1)
2. specs/01_요구사항명세서.md (기준 2)
3. specs/05_공용_인터페이스_명세.md (검증 대상)

## 검증 항목
1. 도메인 분리의 "의존하는 모듈" 전부 추출 → 각 의존에 인터페이스 있는가
2. 요구사항명세서에서 "~하면 ~에게 ~한다" 패턴 → 모듈 간 호출이 인터페이스로 잡혔는가
3. 인터페이스 시그니처에 Object/Map 사용 없는가 (제네릭 필수)
4. 모든 인터페이스에 Stub 동작이 정의됐는가
5. DTO에 불필요한 필드가 없는가
6. 기준에 없는데 인터페이스만 있는 것 (AI 추가)
7. **"권한 체크 위치" 섹션이 단일 값으로 확정됐는가** (Controller 애노테이션 / Service / AOP / Gateway 중 하나). 복수 위치·미확정이면 ❌
8. **소유자/조직 검사 위치가 Service 계층으로 명시됐는가** (권한 모델에 소유자/조직 검사가 있는 경우)
