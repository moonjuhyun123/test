# /review-02 — 도메인 분류 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 이전 세션에서 만든 산출물을 처음부터 읽고 검증한다.
수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/01_요구사항명세서.md (기준)
2. specs/02_도메인_분류.md (검증 대상)

둘 다 처음부터 읽어라.

## 검증 항목
1. 요구사항명세서의 모든 기능/행위를 하나씩 추출해라
2. 각 기능이 02에서 어떤 도메인에 배정됐는지 매핑해라
3. 배정 안 된 기능 목록을 뽑아라
4. 요구사항명세서에 없는데 02에만 있는 행위를 뽑아라 (AI가 추가한 것)
5. 도메인 이름이 모호하거나 너무 넓은 게 있는가
6. 한 기능이 두 도메인에 중복 배정되지 않았는가

## 결과 저장
specs/_reviews/02_review.md

## 출력 형식
```markdown
# 리뷰: 02_도메인_분류.md
- 일시: {타임스탬프}
- 기준: 01_요구사항명세서.md

## 기능 → 도메인 매핑
| 기능 | 배정 도메인 | 상태 |
|------|-----------|------|
| {기능} | {도메인} | ✅ |
| {기능} | — | ❌ 누락 |

## AI 추가 의심
| 도메인 | 행위 | 요구사항명세서에 근거 |
|--------|------|----------------|

## 수치
- 매핑률: {N}/{M} ({%})
- 누락: {N}개
- AI 추가: {N}개

## 판단
✅ 다음 진행 가능 / ❌ 수정 필요 ({사유})
```

## 절대 규칙
- 검증만 해라. 02를 수정하지 마라.
- 숫자로 보여줘라.
