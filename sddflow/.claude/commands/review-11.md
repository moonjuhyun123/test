## 읽을 파일
1. specs/01_요구사항명세서.md (기준 1)
2. specs/06_공통_구조_설계서.md (기준 2)
3. specs/10_표시_데이터_명세.md (기준 3)
4. specs/11_API_스펙.md (검증 대상)

## 검증 항목
1. 요구사항명세서의 모든 사용자 행위 추출 → 대응 API가 있는가
2. 요구사항명세서에 없는데 API만 있는 것 (AI 추가)
3. 응답 형식이 ApiResponse<T> 따르는가
4. 에러 코드가 네임스페이스 규칙 따르는가
5. 통합 디테일 6개 항목 전부 명시됐는가:
   - 날짜 포맷 (ISO 8601)
   - nullable 필드 표시
   - 빈 목록 표현 ([] vs null)
   - 페이징 파라미터명
   - 정렬 파라미터 형식
   - enum 값 표현 (문자열)
6. ★ 표시 데이터 커버리지: 10_표시_데이터의 모든 데이터 항목이 API 응답에 포함되는가
7. ★ 입력 데이터 커버리지: 10_표시_데이터의 모든 입력 항목이 API 요청에 포함되는가
