## 읽을 파일
1. specs/01_요구사항명세서.md (외부 연동 - 필수 목록)
2. specs/05_공용_인터페이스_명세.md (외부 연동 어댑터 포트 목록)
3. specs/17_외부연동_확인리스트.md (검증 대상)

## 검증 항목
1. 01의 "외부 연동 - 필수"에 등록된 모든 시스템이 17에 섹션으로 포함되었는가
2. 05의 외부 연동 어댑터 포트 수와 17의 시스템 섹션 수가 일치하는가
3. 각 시스템 섹션에 다음 4개가 모두 있는가: **위임 범위 / 확인 항목 / 필요 필드 / 없음 대처 경로**
4. 필요 필드 목록의 각 항목이 **출처 파일·출처 위치·사용 코드 근거** 3개를 모두 갖는가 (추측 금지 — 하나라도 비면 ❌)
4-1. 인용된 출처 위치가 실제 산출물에 존재하는가 (grep으로 검증)
4-2. 09·10·11에 등장하는데 17에 누락된 외부 어댑터 관련 필드가 없는가 (역방향 검증)
5. 외부 의존 최소화 원칙이 지켜졌는가 — 위임 범위가 "대체 불가능한 최소 책임"으로 좁혀져 있는가 (예: SSO가 이름·부서까지 반환하는 설계면 ❌)
6. "없음 대처 경로"가 4가지 경우를 모두 다루는가 (없음 / 일부만 / 제약 / 지연)
7. 담당자·연락처를 찾거나 묻는 내용이 들어 있지 않은가 (들어있으면 ❌)
