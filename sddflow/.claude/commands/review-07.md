# /review-07 — 화면 목록 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/01_요구사항명세서.md (기준)
2. specs/07_화면목록.md (검증 대상)

둘 다 처음부터 읽어라.

## 검증 항목
1. 요구사항명세서의 모든 기능(F001~)에 최소 1개 화면이 매핑되었는가
2. 매핑되지 않은 기능 목록을 뽑아라
3. 요구사항명세서에 없는데 화면 목록에만 있는 화면을 뽑아라 (AI 추가)
4. 화면 흐름도에서 도달 불가능한 화면이 있는가
5. 도메인 그룹핑이 요구사항명세서의 기능 분류와 일치하는가
6. 화면 번호가 연속적이고 중복이 없는가
