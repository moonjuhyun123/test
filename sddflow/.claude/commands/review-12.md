# /review-12 — 테스트 케이스 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/11_API_스펙.md (기준)
2. specs/12_테스트_케이스.md (검증 대상)

## 검증 항목
1. API 스펙의 모든 엔드포인트에 테스트 케이스가 있는가
2. 각 엔드포인트에 최소 성공/실패/권한/경계 4종류가 있는가
3. 에러 코드가 API 스펙의 에러 코드와 일치하는가
4. API 스펙에 없는 엔드포인트의 테스트가 있는가 (AI 추가)
5. 경계값 테스트가 현실적인가 (빈값, 최대 길이, 중복 등)

## 결과 저장
specs/_reviews/12_review.md

```markdown
# 리뷰: 12_테스트_케이스.md

## 에러 코드 일치
| API | 스펙 코드 | 테스트 코드 | 일치? |

- 에러 코드 불일치: {N}건

## 판단
✅ / ❌
```
