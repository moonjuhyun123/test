# /review-14 — ERD 최종 확정 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/11_API_스펙.md (기준 1)
2. specs/12_테스트_케이스.md (기준 2)
3. specs/05_공용_인터페이스_명세.md (기준 3)
4. specs/10_표시_데이터_명세.md (기준 4)
5. specs/03_ERD.md (검증 대상 — 세션 14에서 업데이트된 버전)

## 검증 항목
1. API가 참조하는 모든 필드가 ERD에 존재하는가
2. 테스트 케이스에서 사용하는 데이터가 ERD 컬럼과 일치하는가
3. 인터페이스 DTO의 필드가 ERD에서 조회 가능한가
4. 표시 데이터 명세의 ERD 출처가 모두 실제로 존재하는가
5. ERD에 있는데 어떤 API에서도 사용하지 않는 테이블/컬럼이 있는가

specs/_reviews/14_review.md

- 미사용 컬럼: {N}개
