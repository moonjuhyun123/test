# /integration-order — 통합 순서 계산

## 역할
너는 Architect다. Stub 사용 목록을 기반으로 통합 순서를 계산한다.

## 입력
specs/modules/ 폴더의 모든 MODULE_SPEC을 읽어라.
각 SPEC의 "Stub 사용 목록" 섹션을 확인해라.

## 할 일
1. 각 모듈의 Stub 사용 수를 세라
2. Stub 사용 수가 적은 모듈부터 정렬해라
3. 순환 의존이 있는지 확인해라 (A→B, B→A)
4. 통합 순서와 각 단계에서 교체할 Stub을 출력해라

## 출력 형식
```
## 통합 순서

| 순서 | 모듈 | Stub 사용 수 | 교체 대상 |
|------|------|-------------|----------|
| 1차  | {모듈} | 0 | 없음 |
| 2차  | {모듈} | 1 | {인터페이스명} → {실제 구현 모듈} |
| ...  | ... | ... | ... |

## 순환 의존 경고
- {있으면 표시, 없으면 "없음"}
```

## 출력
터미널에 결과를 출력해라.

## 절대 규칙
- 순환 의존이 발견되면 반드시 경고해라
- 통합 순서를 임의로 바꾸지 마라. Stub 수 기준으로만 정렬해라
