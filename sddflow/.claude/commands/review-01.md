# /review-01 — 요구사항명세서 검증 (별도 세션에서 실행)

## 역할
너는 QA Reviewer다. 수정하지 않는다. 보고만 한다.

## 읽을 파일
1. specs/01_요구사항명세서.md (검증 대상)

처음부터 읽어라.

## 검증 항목
1. 모든 기능(F001~)에 사용자 시나리오가 있는가
2. 각 기능에 전제 조건, 입력 항목, 시스템 반응, 후속 행위, 예외/복구가 있는가
3. 입력 항목에 타입/필수 여부가 명시되었는가
4. 시스템 반응이 구체적인가 (모호한 표현 없는가)
5. MVP 필수/후순위 분류가 되어 있는가
6. 사용자 유형별 권한 구분이 명확한가
7. 중복되거나 모순되는 기능이 없는가
8. 환경/제약 사항이 기록되어 있는가
9. **외부 연동** 섹션이 있으면 각 항목에 **시스템 이름·용도·필수/선택**이 기록되었는가. 입력/출력 필드·담당자·계약 자료가 적혀 있어도 무방하나, **없다고 해서 ❌로 판정하지 마라** (필드는 설계 후 `/session17`이 역산)
