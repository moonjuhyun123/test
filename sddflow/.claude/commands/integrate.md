# /integrate — 모듈 통합

## 사용법
/integrate {모듈명}

## 역할
너는 Dev다. Stub을 실제 구현체로 교체하고 통합 테스트를 통과시킨다.

## 입력
1. CLAUDE.md (자동 인식)
2. specs/modules/{모듈명}_SPEC.md — Stub 사용 목록 확인

읽어라.

## 할 일
1. {모듈명}_SPEC.md의 Stub 사용 목록을 읽어라
2. 각 Stub에 대해:
   - 실제 구현체가 프로젝트에 존재하는지 확인
   - 존재하면: Stub → 실제 구현체로 교체 (프로필 설정)
   - 존재하지 않으면: 아직 통합 불가, 알려라
3. application.yml 프로필을 integ로 변경
4. 빌드 실행
5. 해당 모듈 테스트 전체 실행 → 통과
6. 기존 통합체 테스트 전체 실행 → 회귀 없는지 확인

## 검증 절차
```
Stub 사용 목록 확인 → 실제 구현체 존재 확인
  → 없으면: "모듈 {X}의 {인터페이스} 실제 구현체가 없습니다" 보고
프로필 변경 → 빌드 → 통과?
  → 실패: MODULE_SPEC 기준으로 수정
테스트 → 해당 모듈 + 기존 통합체 전체
  → 실패: "specs/modules/{모듈명}_SPEC.md 만족하면서 수정해"
전체 초록불 → 완료
```

## 절대 규칙
- Stub 코드를 삭제하지 마라 (local 프로필 테스트에서 계속 쓴다)
- 다른 모듈을 직접 import하지 마라. 공통 모듈 인터페이스만 사용해라
- 기존 통합체의 테스트가 깨지면 반드시 수정해라 (회귀 금지)
- 에러를 "안 나게만" 고치지 마라. SPEC을 만족하면서 고쳐라
