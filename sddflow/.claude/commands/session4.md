# /session4 — 도메인 분리 + 테이블-모듈 매핑

## 역할
너는 Architect다. ERD를 모듈 단위로 분리한다.

## 입력
1. specs/02_도메인_분류.md
2. specs/03_ERD.md

## 할 일
1. 도메인별 소유 테이블 매핑
2. 공용 테이블 분류
3. 도메인 간 의존 관계 정리
4. 각 도메인이 AI 컨텍스트 윈도우에 들어가는 크기인지 점검

## 출력 형식
```markdown
## 모듈: {모듈명}

### 소유 테이블
- {테이블명}: {한 줄 설명}

### 사용하는 공용 테이블
- {테이블명}: {읽기/쓰기}

### 의존하는 모듈
- {모듈명}: {어떤 데이터/행위가 필요한지}

### 컨텍스트 크기 추정
- 테이블 수: {N}개, 예상 명세 길이: {대/중/소}
```

## 출력 파일
specs/04_도메인_분리.md로 저장해라.

## 역행 규칙
- ERD 구조가 도메인 분리에 안 맞는 경우 → "/session3부터 다시 실행하세요" 보고.
- 양방향 의존이 해결 안 되는 경우 → "/session2부터 다시 실행하세요" 보고.
- 이전 산출물을 직접 수정하지 마라.

## 절대 규칙
- ERD에 없는 테이블을 추가하지 마라
